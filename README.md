# SysPulse — монитор и оптимизатор Windows

Офлайн-приложение для Windows 10/11, которое в реальном времени показывает состояние компьютера, находит проблемы
и помогает их устранить. Интерфейс сделан в стиле MSI Afterburner: тёмная тема, стрелочные индикаторы, графики
мониторинга. Оформление можно менять: доступны скины, свои цвета и оверлей поверх игр.

Программе не нужен интернет. Она ничего никуда не отправляет. Обновление антивирусных баз — единственная
необязательная функция, которой нужна сеть.

## Как получить SysPulse.exe

**Вариант 1 — собрать автоматически на GitHub (ничего не нужно устанавливать).**
После загрузки репозитория на GitHub workflow `.github/workflows/build.yml` сам выполнит все шаги на
`windows-latest`: проверит код (ruff, pyright), запустит тесты, соберёт `SysPulse.exe` и проверит, что он
запускается. Готовый файл появится на вкладке **Actions**, в последнем запуске, в разделе **Artifacts → SysPulse-windows**.
Если создать тег `v1.0.0`, exe будет прикреплён к релизу.

**Вариант 2 — собрать на своём ПК.** Установите [Python 3.10+](https://www.python.org/downloads/windows/) с галочкой
«Add python.exe to PATH» и запустите `build.bat`. Готовый файл: `dist\SysPulse.exe`.

**Вариант 3 — запустить без сборки:** `run.bat`.

`SysPulse.exe` — один переносимый файл, установка не нужна. Настройки, журналы и резервные копии хранятся
в `%APPDATA%\SysPulse`.

## Права администратора

Программа работает и без прав администратора, но часть функций тогда недоступна: очистка системных папок,
службы, записи HKLM, standby-память, время загрузки, S.M.A.R.T., твики с 🛡. Кнопка
«Получить права администратора» в заголовке окна перезапускает программу с запросом UAC.

## Температуры

Windows штатно не отдаёт температуру процессора. SysPulse берёт её из трёх источников:

1. **NVIDIA GPU** — напрямую через драйвер (NVML).
2. **ACPI Thermal Zone** — работает на части ПК, обычно только с правами администратора.
3. **LibreHardwareMonitor / OpenHardwareMonitor** — если одна из этих программ запущена, SysPulse автоматически
   подхватывает её датчики: CPU Package, ядра, GPU, NVMe, вентиляторы, мощность. Это самый точный вариант.

## Безопасность изменений

- Автозагрузка отключается через ключи `StartupApproved`, как в Диспетчере задач, а удалённые записи сохраняются
  в `backups\startup_*.json`.
- Реестр перед исправлением экспортируется в `backups\registry_*\*.reg`. Восстановить можно двойным щелчком
  или кнопкой в программе.
- Все твики обратимы: если снять флажок, вернётся значение Windows по умолчанию.
- Критичные процессы (`lsass`, `csrss`, `winlogon` и др.) и системные службы защищены от завершения и отключения.
- Очистка не переходит по символическим ссылкам и junction-точкам, пропускает занятые и свежие временные файлы
  и не трогает историю, пароли и закладки браузеров.
- Перед серьёзными изменениями создайте точку восстановления: раздел «Оптимизация» → кнопка вверху.

## Структура проекта

```
main.py                     точка входа (единственный экземпляр, журнал)
syspulse/core/              логика без интерфейса
  sensors.py, pdh.py        сбор показателей (psutil, счётчики PDH, NVML, WMI-датчики)
  hardware.py               сведения о компонентах и S.M.A.R.T.
  diagnostics.py            анализ проблем и оценка здоровья
  processes.py, startup.py, services.py, programs.py
  cleaner.py, registry.py, security.py, optimizer.py
  settings.py, winutil.py   настройки и скины, реестр, PowerShell, права
syspulse/ui/                интерфейс PySide6 (Qt 6)
  widgets.py                индикаторы, графики, шкалы в стиле Afterburner
  theme.py, icons.py        таблица стилей из палитры скина, векторные иконки
  main_window.py, osd.py    окно, трей, оверлей
  pages/                    разделы приложения
tests/                      автотесты
```

## Проверка качества

```
pip install -r requirements.txt -r requirements-dev.txt
ruff check .          # стиль и типичные ошибки
npx pyright           # проверка типов для платформы Windows
python -m pytest -v   # тесты
```

Тесты включают:

- логику очистки, автозагрузки, реестра и твиков на имитации реестра;
- синтаксический разбор **всех** генерируемых PowerShell-скриптов парсером PowerShell;
- дымовой тест интерфейса: открываются все страницы, переключаются все скины, работает оверлей;
- на Windows дополнительно — живые тесты PDH, WMI, Defender, служб, автозагрузки и окон.

## Ограничения

- Оверлей — это окно поверх остальных. В играх он виден в оконном и безрамочном режимах. В эксклюзивном
  полноэкранном режиме нужен перехват DirectX, как у RivaTuner, а его в программе нет. Счётчика FPS по той же
  причине тоже нет.
- Очистка реестра почти не ускоряет компьютер. Она убирает следы удалённых программ.
- Разгона и управления вентиляторами нет: для этого нужен драйвер уровня ядра.
